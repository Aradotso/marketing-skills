# strategic-marketing-director-skill

> Skill by [ara.so](https://ara.so) — Marketing Skills collection.

This skill transforms AI agents into strategic marketing directors, equipped with 50+ classic marketing and business models organized into a 4-stage workflow: Diagnose → Strategy → Execute → Review. It provides structured frameworks for marketing decision-making, from market analysis to campaign execution.

## What This Project Does

Strategic Marketing Director is a comprehensive decision-making system that:

- **Integrates 20+ classic analysis models** across 9 categories (strategic, thinking, brand, marketing, growth, psychology, data, operations, sales)
- **Provides a structured workflow** for marketing decisions: diagnosis → strategy → execution → review
- **Automates model selection** based on business scenarios and triggers
- **Enables evidence-based marketing** moving from experience-driven to data-driven decisions

## Core Workflow

The system follows a 4-stage marketing decision workflow:

### 1. Diagnose (诊断阶段)

Analyze the current situation using strategic and thinking models:

```markdown
## Market Analysis Example

**Scenario**: Entering a new market segment

**Models to Apply**:
- Porter's Five Forces (competitive intensity)
- PESTEL Analysis (macro environment)
- SWOT Analysis (internal/external factors)
- 3C Analysis (Company, Customer, Competitor)

**Output**: Comprehensive market diagnostic report
```

### 2. Strategy (策略阶段)

Develop strategic direction using brand and marketing models:

```markdown
## Brand Positioning Example

**Scenario**: Rebranding a B2B SaaS product

**Models to Apply**:
- Positioning Triangle (Target, Differentiation, Support)
- Value Proposition Canvas
- STP (Segmentation, Targeting, Positioning)
- ICP (Ideal Customer Profile)

**Output**: Clear positioning statement and target audience definition
```

### 3. Execute (执行阶段)

Implement campaigns using growth and operations models:

```markdown
## Campaign Execution Example

**Scenario**: Launch a user acquisition campaign

**Models to Apply**:
- AARRR Funnel (Acquisition, Activation, Retention, Revenue, Referral)
- AIDA (Attention, Interest, Desire, Action)
- OKR (Objectives and Key Results)
- PDCA (Plan-Do-Check-Act)

**Output**: Detailed execution plan with metrics and responsibilities
```

### 4. Review (复盘阶段)

Evaluate performance using data and optimization models:

```markdown
## Performance Review Example

**Scenario**: Quarterly marketing performance review

**Models to Apply**:
- NPS (Net Promoter Score)
- LTV/CAC Ratio
- RFM Analysis (Recency, Frequency, Monetary)
- A/B Testing Framework

**Output**: Data-driven insights and optimization recommendations
```

## Practical Usage Examples

### Example 1: New Product Launch Analysis

```markdown
# New Product Launch Analysis

## Phase 1: Diagnose
**Question**: Should we launch this product in market X?

**Apply Models**:
1. PESTEL Analysis → Identify macro environmental factors
2. Porter's Five Forces → Assess competitive intensity
3. SWOT → Internal capabilities vs. external opportunities

**Tools Needed**: Market research data, competitor intelligence, internal capability assessment

## Phase 2: Strategy
**Question**: How should we position this product?

**Apply Models**:
1. STP → Define target segments and positioning
2. Value Proposition Canvas → Map customer pains and gains
3. Positioning Triangle → Craft positioning statement

**Output**: "For [target], who [need], our [product] is [category] that [benefit], unlike [competitors]"

## Phase 3: Execute
**Question**: How do we launch to market?

**Apply Models**:
1. GTM Strategy → Channel and timing plan
2. AIDA → Customer engagement funnel
3. OKR → Set measurable objectives
4. RACI → Define team responsibilities

**Deliverables**: Campaign brief, content calendar, budget allocation, KPI dashboard

## Phase 4: Review
**Question**: Is the launch successful?

**Apply Models**:
1. AARRR Metrics → Track acquisition and activation
2. NPS → Measure customer satisfaction
3. LTV/CAC → Evaluate unit economics
4. PDCA → Identify improvements

**Outcome**: Performance report with optimization recommendations
```

## Troubleshooting

### Issue: "Too many models, don't know which to use"

**Solution**: Start with the 4-stage workflow
- Diagnose → Use SWOT or 3C
- Strategy → Use STP or Positioning Triangle
- Execute → Use PDCA or OKR
- Review → Use Key Metrics Dashboard

Focus on 5-7 core models initially, expand as needed.

### Issue: "Models feel too theoretical"

**Solution**: Always connect models to concrete business questions
- Bad: "Let's do a SWOT analysis"
- Good: "To decide if we should enter market X, let's analyze our Strengths in this context, Weaknesses we need to address, Opportunities unique to this market, and Threats from competitors"

### Issue: "Analysis paralysis - too much planning, not enough action"

**Solution**: Set time limits for each phase
- Diagnose: 20% of project time
- Strategy: 30% of project time
- Execute: 40% of project time
- Review: 10% of project time

Use "good enough" decision-making for low-stakes decisions.

### Issue: "Team doesn't understand the models"

**Solution**: Create visual templates and worksheets
- One-page model summaries
- Fill-in-the-blank templates
- Example case studies
- Facilitation guides for workshops

### Issue: "Data not available for quantitative models"

**Solution**: Start with qualitative frameworks
- Use SWOT instead of BCG Matrix
- Use Customer Journey Maps instead of RFM
- Use expert judgment with structured frameworks
- Build data collection into execution phase

## Best Practices

1. **Always start with the business question**, not the model
2. **Use 2-3 complementary models** rather than applying all models
3. **Involve stakeholders early** in model selection and application
4. **Document assumptions** when data is limited
5. **Create visual outputs** (frameworks are easier to discuss visually)
6. **Iterate quickly** - models are thinking tools, not final answers
7. **Teach the team** - shared mental models improve collaboration
8. **Customize for context** - adapt models to your industry and stage
